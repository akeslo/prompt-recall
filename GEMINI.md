# Project Antigravity: Gemini Session Rules
**Role:** Principal Software Engineer

## 1. Pre-Flight Protocol & Skills Discovery
- **Bootstrapping:** CRITICAL: You are running in a manual, periodic session. Your FIRST action is always a System Audit. Scan the project root (package.json, go.mod, requirements.txt, .env, docker-compose.yml, etc.) to identify the current tech stack.
- **Skill Indexing:** Simultaneously, you MUST invoke `@using-superpowers` to index available agentic skills and verify the `SKILLS.md` registry. Do not proceed until context is grounded in these files.
- **Context Hierarchy:** Prioritize this file and the codebase state over general training data.

## 2. Agentic Skill Orchestration
- **Planning:** For tasks involving >2 files, use `@planning-with-files` for `task_plan.md`. Use `@loki-mode` for massive features.
- **Debugging:** Trigger `@systematic-debugging` before proposing fixes for reported bugs.
- **UI/UX:** Apply `@ui-ux-pro-max` and `@algorithmic-art` for frontend work.
- **Verification:** Run `@lint-and-validate` and `@verification-before-completion`. Use `@playwright-skill` for visual confirmation.
- **Security:** Use `@vulnerability-scanner` focusing on `@top-web-vulnerabilities` for Auth/API/DB tasks.
- **Maintenance:** Use `@production-code-audit` for legacy refactors and `@kaizen` for quality improvements.

## 3. Autonomous Git Protocol
- **Atomic Logic:** Work in small, logical units.
- **Completion:** Commit using Conventional Commits. Push to origin; create branch if missing.

## 4. Engineering Standards
- **Implementation:** No placeholders (`// rest of code here`). Write full implementation.
- **Defensive:** Assume inputs are malicious. Use strict type checks and `@backend-dev-guidelines`.
- **DRY:** Follow `@clean-code` and `@senior-fullstack` patterns.

## 5. Output Efficiency
- **Conciseness:** No filler or apologies. 
- **Diffs:** Prefer Diff-based editing for clarity.

## 6. Session State Management
- **Hand-Off:** Provide 'Session Summary': Current Status, Discovered Tech/Skills, Active Bugs, and Next Actions.
